# 夜幕规则重构基线

## 这份文件解决什么问题

狼人杀不能用一条固定的“守卫 → 狼人 → 预言家 → 女巫”流程覆盖所有板子。每个板子至少要独立定义：

- 角色配置与阵营
- 首夜行动
- 后续夜行动
- 行动先后关系
- 主持人台词
- 公开信息与私密信息
- 技能合法目标
- 技能冲突和结算优先级
- 白天警长、发言、投票、PK、遗言顺序
- 死亡技能和警徽处理
- 胜负条件

当前规则执行代码位于 `src/game/engine.ts`，桌规位于 `src/game/config.ts`，角色注册位于 `src/game/roles.ts`。参考规则与实际软件支持范围分别记录在 `src/game/role-reference.ts`；不能把“查到配置”误标成“已经实现”。下文的实现顺序是建设目标，不代表全部功能已经完成。

## 当前可用的查阅与流程提示（2026-11-15）

- 首页“规则与角色图鉴”提供流程指南、基础规则和当前软件 50 种可选角色的技能资料；范围不等于所有历史版本与扩展牌。
- 板子库现有 31 套可直接使用的阵容：20 套网易来源、5 套京城大师赛来源、6 套线下常用阵容。来源只描述该条目的版本，不代表同一名称在不同赛季沿用同一规则。
- “网易官方”和“京城大师赛”分别筛选。京城条目标为“官方”只限已能看到原始规则图的版本；“参考”条目会在来源与处理范围中明确标注，不冒充节目官配。
- 《盗宝大师》保存 S15 的 15 张完整牌池；开局前自动抽出 3 张底牌，剩余 12 张入座。该板首夜狼队只确认同伴、不发动击杀，盗宝大师阵营由底牌决定。
- 开局设置和主持台均可打开同一离线图鉴。查阅以弹层显示，不卸载当前页面，不清空待确认目标或开局草稿。
- 角色资料可搜索、按阵营筛选或仅查看本局角色；不展示座位与身份的对应关系。
- 每份角色说明列出介绍、行动时机、技能、限制、主持核对点和来源；“自动处理 / 部分处理 / 主持人处理”表示当前软件能力，不表示规则本身的复杂程度。
- 角色介绍核对网易官网图鉴公开资料，寻香魅影另核对官方小助手发布的角色说明。具体赛事和实物牌版本仍须开局确认，尤其不能混同狼王与白狼王、恶灵骑士与恶夜骑士。
- 开局座位页显示桌规核对摘要；主持页按实际阶段显示后续流程和本步核对点，首日警长顺序按本局设置变化。
- 赛前可按首夜夜死、后续夜死、放逐、技能带走和自爆分别开启遗言；命中后进入独立队列，逐人完成或放弃，再处理出局技能、警徽和胜负。
- 夜间行动流程可选择发牌后自行看牌，或“确认即行动”。后者不增加开局逐座核对步骤：按夜间顺序唤醒玩家时先显示本步身份或阵营，确认后立即执行技能，闭眼后完成该步并自动记入身份记录。
- 已出局角色的夜间空唤醒默认保留；只有显式关闭时才跳过。放逐可选择逐人计票或快速记录最终被票出者，快速模式不计算票型和平票。
- 白天发言、警上、PK 和遗言可分别设置计时，旧方案未设置时沿用原发言时长。
- 特殊夜间技能有不少仍仅记录目标，当前人工裁定也只在白天发言阶段可用；图鉴展示了这些边界。查阅与提示不等于补全了特殊技能引擎。
- 界面按窄屏手机、常规平板和展开式平板/横屏布局：600 dp 起使用平板弹层，720 dp 起首页与板子库双列，840 dp 起主持台左右分栏，1200 dp 起增加页面留白。系统字体放大和座位格会按可用宽度减列，不硬塞固定列数。
- 玩家模式先选本局板子，人数随板子确定；自己的身份、其他座位的具体身份猜测、“规则与角色”入口和技能快捷项都只显示当前板子的范围，避免把其他玩法的角色混进来。
- 玩家座位板可直接把一个座位标记为出局或恢复在场；出局座位显示删除线和划痕，顶部同步显示在场人数，身份判断、具体身份与备注不会被清掉。
- 旧版玩家笔记会在读取时自动补出板子信息，原座位、判断、事件和票型不覆盖；无法唯一匹配旧自定义人数时标为“旧版自定义”，不冒充某个正式板子。
- 本文档记录代码与验证状态；安装包只在明确要求打包时生成或发布。

资料来源：网易官网 `https://www.langrensha.com/` 及其公开角色图鉴数据；官方寻香识命说明 `https://www.taptap.cn/moment/380003300654714856`。详细来源标识随角色资料保存，软件查阅无需联网。

## 主持台的正确信息结构

主持台不是“卡片堆叠”，而是一个单步法官控制台：

```text
第 2 夜 / 女巫行动

主持词
女巫请睁眼。今晚的刀口是 7 号。你要使用解药吗？

本步必须完成
[ 不用解药 ] [ 使用解药 ]
毒药：选择目标 / 不使用

规则提醒
本板禁止同夜双药；解药已使用；7 号不可作为毒药目标……

隐私区
主持人私密信息：刀口、查验结果、技能冲突

[返回修改]                         [确认本步]
```

下一步只允许由当前板子的状态机产生，不能由页面随意跳过。

## 标准场首版基线

首个真正实现的板子是 12 人预女猎白：

- 4 狼、4 民、预言家、女巫、猎人、愚者/白痴
- 默认屠边
- 默认有警长
- 首日警长竞选顺序作为板子配置项保存
- 警长候选人先发言，退水后确认候选名单
- 警下玩家投票，平票进入 PK；再次平票按规则处理
- 警长决定后续白天发言方向，警长通常最后发言
- 放逐投票必须支持逐人票型、弃票、平票 PK
- 愚者第一次被放逐时翻牌免死，之后失去投票权；是否计入胜负按本板规则
- 猎人是否能在中毒、被梦亡等情况下开枪由板子设置，不写死在全局角色上

这里的“默认”只是产品预设，不代表所有桌游吧规则一致。开局必须展示桌规摘要并允许主持人确认。

## 规则实现顺序

### P0：先做对的

- 标准场：完整夜间行动、首日警长、发言顺序、放逐投票、平票 PK、愚者、猎人、警徽、胜负
- 规则冲突提示：同守同救、药品限制、不能连续守同人、死亡技能顺序
- 主持词：每个步骤可查看完整台词、简版台词和规则说明
- 事件日志：记录私密动作、公开播报、主持人工裁定

### P1：官方常用变体

- 狼王守卫
- 狼美人骑士

## 不能再犯的实现错误

- 不能用角色名称推断夜间顺序。
- 不能用“神职”这个大类推断技能都在同一阶段结算。
- 不能把女巫、猎人、白痴、狼王的死亡技能写成全局固定行为。
- 不能把所有板子的胜负都写成简单的“狼人数量和好人数量比较”。
- 不能把主持词写成一句固定的“请睁眼”，必须告诉主持人下一步要收集什么。
- 不能把有来源的配置和已验证的规则混在一个“支持”状态里。
