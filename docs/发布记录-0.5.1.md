# 夜幕 0.5.1 变更摘要

日期：2026-11-14。版本 `0.5.1`，Android `versionCode` 6，包名不变。

## 赛前设置记忆

- 开局后自动记住板子、身份顺序、桌规、发言设置、主持流程、玩家姓名和对局名称。
- 首页可直接「按上次设置直接开局」，也可以进入设置页检查修改；设置页会自动带入全部上次内容。
- 设置页新增「从头设置」，可清空记忆并回到当前模式的默认板子和桌规。
- 进行中的对局被替换前会确认；旧局会先备份，不会静默覆盖。
- 牌池型板子仍会重新洗牌扣底，不会复用旧底牌。
- 没有新记忆时，会从当前对局或最近复盘反推设置。
- 「上次设置」随本机备份导出；损坏的记录会被隔离，原有方案不受影响。
