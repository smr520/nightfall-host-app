# 赛前设置记忆

这一版解决的是重复开局的浪费：同一桌人连续玩时，板子、桌规、阵容人数和已填姓名可以预填，但每一局仍要重新核对座位并在夜间确认身份。

## 会记住什么

一局真正开始后，应用自动保存这次开局的完整设置：

- 板子名称与板子编号；自定义阵容会保存实际身份列表。
- 阵容中的角色清单和人数；不再把上一局“某号坐某身份”当作新局答案。
- 全部桌规：警长、胜负、女巫与守卫限制、平票、发言时长、主持流程和本桌补充约定。
- 每个座位填写的玩家姓名。
- 对局名称和主持方式（标准流程 / 熟人快局 / 我的方案）。

这份记忆只保存在本机，并随「本机数据」备份一起导出。备份里本来就包含身份与对局记录，仍然只应分享给可信的人。

## 首页怎么用

有上次设置时，开局卡片会显示：

- `上次开局已记住`
- 板子名称、人数和桌规摘要
- `新建一场对局`：进入设置页，所有内容已经带入，可以逐项检查后修改。
- `沿用上次设置，重新确认`：只预填板子、桌规、姓名和对局信息，仍进入三步设置。
- `从头设置`：在设置页顶部清空记忆，回到当前模式的默认板子和桌规。

如果当前还有一局没结束，仍可先进入新局设置；只有走完设置并点“开始主持”时才会弹出替换确认。确认后先备份并移除旧局，再开始新局，不会在刚进入设置页时提前丢掉旧局。

## 设置页怎么用

从首页进入「新建对局」时：

- 板子、桌规、姓名和对局名称已经带入。
- 顶部显示「已带入上次开局设置」，但必须继续完成板子、桌规和座位确认，没有“直接开局”入口。
- 默认“确认即行动”模式下的座位页不显示每个座位的身份牌，也不提供赛前身份互换；身份在夜间角色行动时逐项确认。
- 「从头设置」会清空上次带入的内容，重新从默认板子开始。
- 牌池型板子（京城盗宝大师）会重新洗牌扣底，不会复用上一局的底牌。

「我的方案」仍然保留：适合保存多套固定阵容。自动记忆只保存最近一局，相当于不用命名、不用维护的快捷方案。

## 旧数据

旧版本没有这份记忆时：

- 如果还有进行中或最近结束的对局，首页会从该对局反推可复用设置，但新局仍须重新确认座位。
- 如果只有历史复盘，也会取最近一场反推。
- 导入旧备份不会报错；无效的「上次设置」会被丢弃并保留其他可用方案，读取时先备份原始数据。

## 验证

- 纯逻辑测试覆盖设置校验、固定板子复用、自定义阵容重建、牌池重新洗牌和从旧对局反推。
- 界面测试覆盖设置页自动带入、强制三步确认、从头设置和首页“重新确认”入口。
- 应用级测试覆盖首局保存设置、重启后仍走设置流程，以及进行中只在实际开始新局时确认替换。
