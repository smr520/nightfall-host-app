# 官方规则与线下主持差异核对

核对日期：2026-11-14。本文是资料研究，不是某场比赛的完整执裁手册，也不表示软件已经实现全部角色效果。

## 读取方法与范围

实际联网读取了以下 8 份有可读正文的官方资料：3 份线下赛事规则、3 份线上赛事规则、1 份守卫攻略、1 份官方卡牌数据。官网首页用于发现链接，不计作规则资料。正文通过 HTTP 获取；卡牌数据仅提取和解码字符串，没有执行远程脚本。下面引用的是页面短摘录，产品建议另行标记。

不能把“赛点可自定赛制”理解成可以任意修改该官方赛事的角色技能。赛制、积分、桌规和角色技能属于不同层次。线上赛事资料仅作版本对照，不能作为所有线下桌游吧的统一规则。

## 尚不能从上述资料确证的桌规

以下项目适合进一步收集或由开局主持人明确选择，但本轮不能仅根据这些来源填一个“全国统一标准”：

| 项目 | 本轮证据能说明什么 | 仍须确认什么 |
| --- | --- | --- |
| 遗言 | 读取到的正文没有完整遗言政策 | 首夜夜死、后续夜死、放逐、开枪带走、自爆、殉情是否有遗言；何时说、说多久 |
| 警长 | 官方有竞选、警徽移交、狼人警徽记分 | 警长死亡公布前后竞选；PK 轮数；无人上警与再次平票政策 |
| 放逐 PK | 官方细则确有 PK 和 PK 中自曝 | 第一轮平票是否直接无人出局；再平票是否继续；谁可投票 |
| 女巫 | S8 是不可自救、每夜最多一药 | 本桌是否改成首夜自救、允许同夜双药；解药耗尽后是否告知刀口 |
| 守卫 | S8 不可连守；S7 支持空守/自守 | 本桌是否修改连守/自守；与女巫救药冲突如何处理 |
| 猎人 | S8 对刀死和放逐给出开枪权 | 其他死因与特殊技能联动的本桌约定 |
| 自爆 | 白狼王与狼王不同；PK 中自曝被赛事考虑 | 允许自爆的阶段；是否吞警徽；自爆后有无遗言与技能顺序 |
| 胜负 | S6 明确存在第三方胜利 | 每个特殊板型的胜利优先级、是否结算完死亡技能再判胜负 |

以上“仍须确认”是产品需求候选，并不代表所有变体都得到官方赛事认可。以自定义功能承接用户本桌约定时，应标为“本桌约定”，保存到方案中并在赛前宣读。

## 对个性化设定的设计结论

以下是本次研究后的产品判断，不是来源原话：

1. 个性化应发生在开局前，以“这桌怎么玩”为入口，先选板型，再只显示相关桌规，最后形成一段可直接宣读的赛前说明。
2. 一份“我的桌规”应保存阵容、规则、夜间顺序、发言计时和主持词，便于熟人桌重复使用。不要用“标准流程”四字掩盖未确认的版本差异。
3. 影响结算的设置必须贯穿设置页面、引擎验证、结算、主持词、存档校验和回归测试；不支持自动结算的特殊技能应清楚告知主持人需要手动处理。
4. 场内默认展示可直接读出的完整台词；隐私信息另放主持人可见区域。出局、弃权、跳过无行动角色和放弃死亡技能都应有明确的下一步。
5. 仅调整显示/话术的设置与会改变玩法的桌规须清晰区分。关于遗言、第三方和复杂技能，先补齐证据和状态机，再开放具有自动效果的选项。
