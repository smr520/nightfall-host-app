# 板子库与主持界面改版

这一轮针对反馈里的三个问题：板子太少、有的板子点不了、界面不好看；
以及第二轮反馈：不要把功能都堆在一个页面上。

## 1. 角色从 7 个扩到 32 个

`src/game/roles.ts` 是新的角色注册表，每个角色包含：

- 名称、短名、阵营（wolf / good）
- 夜间行动的**顺序号**、主持人台词、规则提示、是否可以空过、是否只在首夜行动
- 出局后是否需要主持人处理（`shot` 开枪、`link` 殉情）

引擎不再写死 `guard → wolves → seer → witch`。开局时按本局角色构成生成 `nightCalls`，
夜里逐个推进，出局角色自动跳过，首夜限定技能在第二夜开始自动跳过。

## 2. 板子库：31 个阵容，全部可开局

`src/game/boards.ts`：

| 分类 | 数量 | 说明 |
|---|---|---|
| 网易官方 | 20 | 城市联赛 12 人板、狼王计划、觉醒骑士、沙龙之夜、奇迹商人、恶灵骑士、孤独少女、觉醒狼王、寻香识命 |
| 京城大师赛 | 5 | 盗宝大师、青丘夜影、假面舞会（12/10 人）、机械狼通灵师 |
| 常规 | 6 | 六人速开、八人局、九人标准、十人局、预女猎守、十五人局 |

- 所有板子都是完整阵容，`isPlayable` 全部通过；不再有“模板”或“补齐阵容”流程。
- 板子介绍页展示来源、版本和原始链接；京城牌池型板子在选板时自动洗牌扣底。
- 「自己配一套阵容」仍可从零搭板：狼人 / 神职 / 村民分别加减数量，实时显示总人数。

## 3. 夜间行动的真实口径

- 狼人、预言家、女巫、守卫仍是精确结算（刀口、解药、毒药、守护、同守同救）。
- 其他神职与特殊狼人（骑士、狼美人、噩梦之影、蚀时狼妃、摄梦人、魔镜少女等）由引擎
  记录目标与顺序，具体效果交给主持人按本桌规则裁定，并在「夜间行动已记录 N 项」里提示。
- 狼王 / 白狼王 / 觉醒狼王 / 猎人出局会生成「带人」待处理项；狼美人出局会生成殉情结算。
- 胜负按阵营判定，不再写死 `role === 'wolf'`。

## 4. 界面：从一页到底改成多页

主持台按职责拆成四个页面，用底部标签切换，不再把功能堆在同一张滚动页上：

| 页面 | 内容 |
|---|---|
| 主持 | 当前阶段台词、唯一的目标选择区、主/次操作按钮 |
| 座位 | 存活统计、身份开关、点座位看身份与出局原因 |
| 记录 | 本夜行动汇总 + 按天分组的时间线（区分私密记录与公开播报） |
| 更多 | 对局信息、桌规、撤回/重做、结束本局、移除本局 |

- 新建对局拆成 板子 → 桌规 → 座位 三步。
- 页面切换按空间方向做 220ms 的滑入淡入（只动 transform / opacity），
  跟随系统的「减少动态效果」；测试环境关闭动画以保证确定性。
- 投票、自爆、人工裁定、结束确认仍然以底部弹层出现，避免打断当前阶段。
- 首页 / 复盘是两个独立页面，复盘内含身份表与完整时间线。

## 5. 存档

存档 schema 升到 `2`，新增 `nightCalls` 与 `night.targets`。旧存档（schema 1）在读取时
自动补全并校验；阶段与角色构成不一致的旧档会被拒绝而不是猜测修复。
