# 夜幕 0.5.0 变更摘要

日期：2026-11-14。版本 `0.5.0`，Android `versionCode` 5，包名不变。

## 板子

- 原 5 个“核心牌模板”全部补成 12 人完整官方板：奇迹商人、恶灵骑士、孤独少女、觉醒狼王、寻香识命。
- 板子库现在只包含完整、可开局的阵容；模板标签和“补齐阵容”流程已移除。
- 新增板子来源和版本信息，介绍页可直接打开原始公告或规则图。

## 自动结算

- 毒师、舞者舞池、九尾标记与猎杀时刻、白泽传承、机械狼学习、盗宝大师借用与阵营、沙龙之夜咒狐胜负改为自动结算。
- 新增特殊状态存档字段，旧存档缺少该字段时按空状态读取。

## 屏幕适配

- 手机、折叠屏、平板竖屏 / 横屏、大屏平板采用统一断点布局。
- 大屏主持页分栏显示主持操作与座位。
- 弹层在平板上居中显示，长文限制阅读宽度。
- 详见 `docs/设备与屏幕适配.md`。

- `tsc --noEmit`、ESLint、引擎冒烟、回归脚本通过。
