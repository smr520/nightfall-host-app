# 设备与屏幕适配

本次适配覆盖 Android 手机、折叠屏、平板（竖屏与横屏）以及大屏平板电脑。所有布局由窗口宽度实时计算，旋转、分屏或折叠屏展开后会自动重排，不需要重启对局。

## 断点

| 宽度 | 布局 | 典型设备 |
| --- | --- | --- |
| `< 600` | 手机单列 | 普通手机、折叠屏折叠状态 |
| `600–839` | 平板单列、加宽留白 | 小平板竖屏、手机横屏 |
| `840–1199` | 大屏分栏 | 平板横屏、折叠屏展开 |
| `≥ 1200` | 大屏分栏、最大内容宽度 1180 | 平板电脑横屏 |

断点定义在 `src/ui/responsive.ts`，页面通过 `useResponsive()` 读取。

## 各页面布局

- **主持台**：手机单列；大屏左侧为对局与开局卡片，右侧为最近复盘。
- **新建对局**：板子库在平板上双列展示；座位名单在平板上双列；内容限制最大宽度 1180。
- **主持中对局**：宽度 ≥ 840 时自动分栏，左侧主持操作，右侧固定座位一览；手机与竖屏平板保持四个底部页签。
- **技能表**：宽度 ≥ 1000 时双列卡牌；详情页限制长文阅读宽度 760。
- **个性化 / 复盘 / 数据备份**：内容居中限制宽度，方案和长文不会拉成超长行。
- **底部弹层**：手机上仍是底部抽屉；平板上变成居中对话框，最大宽度 760。
- **底部页签**：平板上限制最大宽度 620，避免按钮分散到屏幕两端。

## 其他细节

- 页面左右留白随宽度从 24 增加到 32；安全区四边都生效，横屏时不会被刘海或圆角遮挡。
- 布局计算支持系统字体缩放至 2.0；座位格最小宽度和高度同步增加，并优先减少列数而不是挤压文字。
- 个性化设置提供“标准 / 大字 / 超大”主持提词档位，只放大完整台词、结果和关键提示，避免把全部操作控件一起撑大。
- 座位网格最多 8 列（大屏）、6 列（平板）、4 列（手机）。
- `app.json` 允许旋转并开启 `resizeableActivity`，支持分屏和折叠屏尺寸变化。
- 响应式逻辑是纯函数，测试见 `scripts/responsive.test.ts`。

## 未覆盖

- 目前只构建 Android 包；iOS / iPad 需要单独配置签名与构建流程。
- 超宽桌面浏览器没有专门做多窗口布局，仍按 ≥ 1200 的大屏分栏显示。
