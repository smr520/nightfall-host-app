# 夜幕 0.4.0 Android 测试包

日期：2026-11-14。Android versionCode 为 4，包名沿用 `com.nightfall.werewolfhost`。

## 本次包含

- 白色界面重新排版：首页、主持台、开局步骤、技能表、个性化、座位与发言计时。
- 统一线形图标、按钮反馈、页面方向切换、导航标记及弹层动画；尊重系统减少动态效果。
- 23 个板子及模板介绍、卡牌类型区分与赛前现场处理清单。
- 按得票人批量录票、修改已录票、警上及 PK 发言、临时发言与出局玩家遗言。
- 自定义方案复制、私密现场备忘、手动判定胜负与第三方胜利选项。
- Android 文件备份、导入预览与恢复、文字复盘分享。
- 此前未发布的角色出局规则、天亮草稿、女巫规则、存储并发与存档校验修复。

## 打包前验证

- TypeScript、ESLint、引擎冒烟及既有流程回归通过。
- Jest 全量 34 个套件、524 项测试通过，包含 180 局确定性整局测试。
- Android Metro/Hermes 导出通过：810 个模块，字节码 2,311,579 字节。
- 快速关闭重开弹层、迟到的动画回调及减少动态效果切换已加入专项回归。
- 默认 Expo 配置只启用 Android；浏览器临时存储和截屏适配仅在显式预览环境且目标为 web 时启用，不进入 Android 存储路径。

## 验收边界

本记录不代表已经完成 Android 真机安装、触控、键盘、文件权限或最终视觉验收。特殊卡牌的部分机制仍按赛前处理清单由主持人操作，不能理解为所有技能均已自动结算。

## 开发预览

可在 PowerShell 中设置 `$env:NIGHTFALL_UI_PREVIEW='1'`、`$env:EXPO_NO_WEB_SETUP='1'`，再运行 `npx expo start --web --localhost` 查看实际 React Native 界面的浏览器渲染。该模式使用独立的内存数据，不读取 Android 真机存档，也不能验证 Android 的防截屏及 SQLite 原生行为。
