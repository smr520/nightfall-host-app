# 夜幕 · 狼人杀主持助手

面向线下狼人杀主持人的离线 Android 工具。它负责赛前配置、夜间行动记录、天亮复核、投票、技能提示和复盘；玩家模式单独保存自己的选本、身份、座位判断、出局状态和笔记。主持数据与玩家笔记互不覆盖。

## 当前能力

- 31 套完整阵容与 50 种角色资料，覆盖网易公开板、京城大师赛公开资料和常规线下阵容。
- 主持人可自定义桌规、夜间顺序、主持词、发言时间、警长与平票策略，并查看每套板子的玩法介绍、来源和处理边界。
- 手机、平板和横屏采用自适应布局；主要触控目标不小于 48 dp。
- 玩家先选板子，再选择自己的座位和身份；其他板子的角色不会混入当前笔记。
- 玩家座位可标记出局或恢复在场，并同时编辑身份判断、具体身份和备注。
- 本地自动保存、进行中恢复、历史复盘、JSON 备份与恢复、旧存档迁移。
- 无需账号、联网、相机、麦克风或定位权限。Android 会阻止主持界面的普通截屏与录屏。

## 重要边界

这是线下主持辅助工具，不是线上狼人杀客户端，也不是网易或京城大师赛的官方产品。板子名称和规则资料用于识别、研究和线下主持，相关商标及第三方资料权利归原权利人。

角色图鉴中存在“自动处理、部分处理、主持人处理”三档说明。骑士决斗、守墓人信息、部分觉醒与第三阵营技能等复杂机制仍需要主持人按赛前桌规裁定；软件不会把未完成的技能伪装成自动结算。具体边界以应用内技能表和 `docs/` 中已核对规则为准。

## 下载与安装

Android APK 发布在仓库的 Releases 页面。正式包使用固定发布签名，后续版本可覆盖安装；如果手机里还安装着旧仓库的测试包，首次切换可能需要先卸载一次。

该 APK 适合直接安装测试，不包含 Google Play 商店发布配置。应用只在本机保存数据，卸载应用会删除本机对局与笔记，请先在“个性化 → 本机数据”中导出备份。

## 开发

环境要求：Node.js 24、npm 11、Java 17。原生 Android 构建还需要 Android SDK 36。

```powershell
npm ci
npm run typecheck
npm run lint
npm run test:engine
npm run test:regressions
npm run test:ui
```

使用 Expo Go 或本地模拟器启动：

```powershell
npm start
```

浏览器只用于界面预览，不能代替 Android 的 SQLite、防截屏、触控和安装测试：

```powershell
$env:NIGHTFALL_UI_PREVIEW='1'
npx expo start --web
```

生成原生工程后，可在具备 Android SDK 的电脑上构建：

```powershell
npx expo prebuild --platform android --no-install
Set-Location android
.\gradlew assembleRelease
```

没有签名环境变量时，本地 Release 构建会回退到调试签名。正式 CI 发布必须配置仓库 Secrets，具体步骤见 [GitHub Actions 构建说明](docs/GitHub%20Actions生成APK.md)。

## 项目结构

- `src/game/`：纯 TypeScript 规则、板子、流程、结算与存档结构。
- `src/ui/`：主持端、玩家端、设置、技能表与复盘界面。
- `src/player/`：玩家笔记模型、存档迁移和本机存储。
- `src/storage*.ts`：主持会话、历史和恢复数据。
- `scripts/`：单元、整局模拟、回归和界面测试。
- `docs/`：规则来源、流程说明、设备适配与构建记录。

## 数据与隐私

应用不请求网络权限，不包含遥测、广告或账号系统。主持人和玩家的数据都在本机，导出备份、分享复盘和分享原始恢复数据都包含私密身份信息，应用会在操作前提示确认。原生 Android 上无法阻止专业外置采集设备，因此主持人仍应确认操作屏幕不会被玩家看到。
